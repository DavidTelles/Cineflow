# 🎬 Cineflow

> Um aplicativo web estilo Netflix desenvolvido com Next.js para explorar, pesquisar e visualizar detalhes de filmes utilizando a API do TMDB.

## 🚀 Tecnologias Utilizadas

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Biblioteca UI:** [React](https://react.dev/)
* **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
* **Dados:** [TMDB API (The Movie Database)](https://www.themoviedb.org/)
* **Hospedagem:** [Vercel](https://vercel.com/)

---

## ✨ Funcionalidades

* 🌟 **Banner em Destaque:** Exibição dinâmica de filmes populares com sinopse e atalhos rápidos.
* 🎞️ **Carrossel Interativo:** Listagem de filmes em descoberta com navegação fluida por setas.
* 🔍 **Busca de Filmes:** Sistema de pesquisa integrado.
* 📄 **Página de Detalhes:** Visual imersivo estilo streaming contendo sinopse, nota de avaliação, ano e gênero.

---

## 🔮 Futuras Implementações (Roadmap)

*   👤 **Autenticação de Usuários:** Sistema completo de cadastro e login seguro utilizando **NextAuth.js** integrado com **Prisma ORM** e **PostgreSQL**.
*   ❤️ **Lista de Favoritos:** Capacidade para usuários autenticados marcarem e desmarcarem filmes favoritos salvos diretamente no banco de dados relacional.
*   📋 **Watchlist Personalizada:** Gerenciamento de uma lista de "Assistir Depois" para acompanhar filmes pendentes.

## 🛠️ Como Rodar o Projeto Localmente

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/DavidTelles/Cineflow.git](https://github.com/DavidTelles/Cineflow.git)
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd Cineflow
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```

4. **Configure as variáveis de ambiente:**
   Crie um arquivo .env.local na raiz do projeto e adicione sua chave de acesso da API do TMDB:
   ```Snippet de código
   TMDB_API_TOKEN=seu_token_de_acesso_aqui
   ```

4. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

5. **Acesse localhost:3000 no seu navegador.**
